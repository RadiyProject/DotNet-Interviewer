# Моковые интервью и ревью

Во вкладке **AI-интервью** сохрани профиль: резюме, легенду (проекты, личный вклад, решения и достижения), целевую роль и вакансию. Поддерживаются PDF, DOCX и TXT/MD в UTF-8, до 2 МБ. PDF разбирается локально в браузере с помощью поставляемой в проекте PDF.js 6.4.299; ни токен, ни Codex-мост, ни установка Python-пакетов не нужны. Лимиты PDF: 30 страниц и 50 000 символов, обработка до 30 секунд. PDF с паролем запрашивает его локально, без сохранения пароля. Сканы без текстового слоя требуют предварительного OCR; о страницах без текста смешанного PDF выводится предупреждение. Проверь извлечённый текст и порядок колонок, затем сохрани профиль. Исходный PDF не отправляется серверу или AI: в профиль попадает только проверенный текст. Сложная верстка и нестандартные шрифты могут потребовать ручной корректировки. Внешние документы считаются данными, а не инструкциями для ассистента.

Сценарий работодателя задаётся отдельно: зарплатная вилка, оформление, команда, процессы, on-call. Неизвестные факты оставляй пустыми: ассистент должен признать отсутствие информации. Легенда используется для тренировки и не объявляется проверенным опытом.

Кнопка «Подготовить интервью» создаёт раунд без запуска таймера. Сначала подключи ассистента и передай контекст; затем нажми «Начать интервью» на странице или в расширении. До этого дедлайна нет, после старта он хранится на сервере и не сбрасывается повторным нажатием. Есть HR/скрининг, технический раунд, лид/hiring manager и финал по ценностям и взаимным ожиданиям. В каждом раунде можно отвечать, уточнять, задавать встречные вопросы, просить подсказку и переходить дальше. После сохранения действия нажми получение ответа ассистента. Технический раунд выбирает задания из банка по тегам: открой задание, отправь решение обычным способом, вернись во вкладку интервью и приложи результат из истории. AI не запускает тесты самостоятельно.

При завершении сразу сохраняется статистическая сводка. Нажми **Получить AI-сводку** для содержательного разбора: что получилось, пробелы, комментарии, вопросы для уточнения и план действий. Оценки 0–4 требуют свидетельств; непроверенные навыки должны оставаться без оценки. Это учебная обратная связь, а не решение о найме. Новый раунд того же профиля может получить сводку предыдущего завершённого раунда.

## Codex CLI

На компьютере нужны установленный актуальный **Codex CLI** и выполненный `codex login`. Авторизация CLI не переносится в Docker. Из корня проекта запусти:

```sh
python3 tools/ai_bridge.py
```

Сайт открывай через `http://localhost:8080`. Если используешь `http://127.0.0.1:8080`, запускай мост с `--origin http://127.0.0.1:8080`. В настройках вкладки вставь выданный мостом токен и разреши передачу выбранных данных. Токен хранится в sessionStorage текущей вкладки. Проверка подключения подтверждает наличие CLI, но доступ к аккаунту проверяется при первом запросе. Необычный путь CLI можно указать через `FORGE_CODEX_BIN`, модель — через `FORGE_CODEX_MODEL`.

Мост слушает только 127.0.0.1:8766 и принимает запросы с токеном и разрешённым Origin. CLI запускается без shell-интерполяции, в отдельном временном каталоге, с read-only sandbox и отключёнными shell, приложениями, плагинами, hooks и браузером. Используются `--ignore-user-config`, `--ephemeral` и JSON schema. Старому CLI может потребоваться обновление. Таймаут — 180 секунд. Временные файлы моста удаляются автоматически; сервис провайдера и сам CLI могут вести свои журналы согласно их настройкам. Это не отдельный контейнерный security boundary.

Резюме, легенда, переписка и выбранный код отправляются через твой аккаунт только по явному действию. Возможен расход лимитов/оплата согласно аккаунту. Ключ OpenAI API для этого режима не нужен. [Документация non-interactive Codex](https://developers.openai.com/codex/noninteractive/).

## ChatGPT Voice и другие ассистенты

Для настоящего голоса ChatGPT добавлено локальное расширение Chrome/Edge **tools/chatgpt-companion**. Оно автоматически получает привязку к открытому интервью через локальный сервер после подтверждения на его странице; копирование токена не требуется, в том числе при тренажёре в Safari. Затем расширение связывает вкладку ChatGPT, передаёт выбранный контекст и сохраняет видимую расшифровку. Итоговый разбор и ревью выполняет Codex CLI. Это автоматизация интерфейса, без Realtime API-ключа. Голос остаётся в ChatGPT; его нужно завершать там вручную. [Установка и полный сценарий](CHATGPT_VOICE.md).

Встроенный голос Codex/Work с инструментами проекта может управлять сессией через **tools/interview_session.py**. Сценарий доступен в ручном разделе вкладки AI. Для других приложений есть передача готового сценария и импорт расшифровки с ролями; JSON после каждой голосовой реплики не требуется. Прежний обмен отдельными JSON-ответами по schema также сохранён.

Озвучивание и диктовка браузера — отдельные вспомогательные кнопки, не голос ChatGPT. Диктовка может обрабатываться провайдером браузера и включается только кнопкой.

## Качество кода

В практических C#/SQL заданиях добавлен блок качества: статические сигналы, Codex CLI review и ручной обмен пакетом с другим AI. Статический анализ — осторожные эвристики с номерами строк, без оценки грейда или доказательства сложности алгоритма. AI получает контракт, снимок кода и результат именно такого отправленного решения, если он есть. Отсутствие результата явно обозначается. После получения AI-подсказок открытая попытка становится учебной; прошлые самостоятельные отправки сохраняют статус. После изменения кода запроси новое ревью. Сохранённые завершённые AI-ревью доступны по отдельной кнопке истории в этом блоке.

Профили, сессии и ревью хранятся в существующем SQLite progress volume. Экспорт во вкладке включает резюме и переписку; отдельный автоматический импорт этого экспорта пока не реализован. Удаление профиля удаляет его раунды. Не сохраняй в легенде секреты работодателей.
