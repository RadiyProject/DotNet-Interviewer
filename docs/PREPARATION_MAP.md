# Направления подготовки

Тренажёр предназначен для подготовки к техническим собеседованиям у разных работодателей. Начальный уровень можно оценить по заданиям, затем выбирать темы по результатам и требованиям интересующих вакансий.

| Направление | С чего начать |
|---|---|
| C# и ресурсы | T01, T12–T13, C07, Q001–Q006 |
| Async и concurrency | C06, C10, C11–C12, C32–C33, C38, C47 |
| Кэширование и stampede | C47, Q165–Q172, A52–A54 |
| LINQ и SQL | T02–T03, C09, SQL01-PG и связанные задания |
| EF Core | C24–C25, C34–C35, C46, A49 |
| Тестирование | T08, C37, A28 |
| Архитектура и сервисы | T14–T15, A23–A25, A35–A38 |
| Эксплуатация | A32–A34 |
| Git | Q123–Q134, A42–A43 |
| NoSQL | Q143–Q152, A45–A48, C44–C45 |

Решай задачи на время, разбирай результат и повторяй материал с интервалом. Ограничения конкретных проверок описаны в условиях упражнения; письменные задания используют рубрику самооценки.
