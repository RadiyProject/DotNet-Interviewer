# Практика проведения code review

Открой «Архитектура и ревью», выбери тему «Code review». Читай исходный фрагмент отдельно от редактора: исправлять его напрямую не требуется, сохраняются твои замечания и аргументы.

Фрагменты авторские, намеренно дефектные. Зависимости и требования указаны в условии; полная инфраструктура приложения не подразумевается и не запускается.

Исключение — A67: допустим обоснованный вывод об отсутствии существенных дефектов. В A59–A67 изучены конкретные исходники обычных GitHub-библиотек и приложений, а учебные фрагменты составлены отдельно с явными условиями. Дефекты упражнений не приписываются upstream-проектам. [Источники, версии и характер адаптации](GITHUB_REVIEW_PACK.md).

## Самостоятельно

1. Прочитай контракт, начни попытку и сначала назови инварианты.
2. Для каждого замечания запиши: серьёзность → строка/выражение → конкретный сценарий → минимальное исправление → проверка.
3. Отдели доказанные дефекты от рисков, зависящих от допущений, и от стиля. Укажи, что уже сделано правильно.
4. Отправь ревью до дедлайна. Рубрика является самооценкой; содержательный разбор открывается как учебная помощь или после завершения.

## С текстовым ассистентом

Настрой Codex CLI по README и разреши передачу материалов. Кнопка «Оценить моё ревью · Codex CLI» отправляет исходный фрагмент, условие и твой текст. Отдельный режим оценивает качество проведённого ревью: верные находки, существенные пропуски, ложные срабатывания, приоритеты, исправления и план проверок. Это не запрос написать решение вместо кандидата.

Замечания содержат evidence и уровень уверенности; уточнения и ступенчатые подсказки помогают продолжить работу. Сохранённые ревью и русский перевод доступны из блока качества. Для другого текстового ассистента есть экспорт пакета и импорт ответа по JSON-контракту. Открытие AI-пакета с эталоном и запрос помощи отмечают активную попытку как учебную.

## С голосовым интервьюером

Создай план в конструкторе, включи нужное задание и запусти технический или лидский AI-раунд. Подключи расширение к ChatGPT, передай контекст и самостоятельно включи Voice.

Открой задание из раунда, напиши замечания и нажми «Обсудить моё ревью с интервьюером». В контекст попадут неизменяемый исходный фрагмент и твой письменный отзыв. Попроси задавать уточнения по одной проблеме: почему это дефект, как его воспроизвести, что исправить минимально, какие альтернативы есть. Новая редакция замечаний передаётся повторным нажатием.

Если Voice скрывает поле ввода, сообщение может ждать окончания голосового режима. Интервьюер не наблюдает редактор непрерывно. Отправленный результат письменной задачи можно приложить к раунду; после синхронизации разговора доступен общий разбор Codex CLI.

Ни AI-оценка ревью, ни галочки рубрики не доказывают корректность программы. Исполнение фрагментов, SQL и изменение реальной БД для этих заданий не выполняются.
